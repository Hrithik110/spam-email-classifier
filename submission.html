a. Problem Statement

The goal is to predict whether an email is spam or not spam using numerical features extracted from the email body (word frequencies, symbol frequencies, and capital-letter run statistics). Five classification algorithms are trained on the same dataset, evaluated on a held-out test set using six standard metrics, and served through an interactive Streamlit application that accepts any compatible test CSV and returns predictions without retraining.

b. Dataset Description

  • Source: UCI Machine Learning Repository — Spambase
  • Total instances: 4 601 emails
  • Total features: 57 input features + 1 target column (is_spam)
  • Class distribution: 2 788 not-spam (60.6 %) · 1 813 spam (39.4 %)
  • Missing values: None

Feature Groups

GroupCountDescription
Word frequency48Percentage of times a specific word (e.g. "free", "money") appears in the email
Character frequency6Percentage of characters that are ; ( [ ! $ #
Capital-letter runs3Average / longest / total length of unbroken sequences of capital letters

The data was split 80 / 20 (stratified, random_state=42). A StandardScaler was fitted on the training portion only and applied to both splits. The 921-row test set is saved as test_data.csv and used by the Streamlit app.

Observations

ML Model Name Observation about model performance
Logistic Regression Best accuracy (92.94 %), highest AUC (0.9702) and highest MCC (0.8518). Train accuracy is 93.07 % — almost identical to test accuracy — confirming no overfitting. The decision boundary found by the linear model generalises very well to this feature set.
Decision Tree Train accuracy was 99.97 % but test accuracy dropped to 91.10 %, a clear sign of overfitting. The tree memorised the training data. It also has the lowest AUC (0.9078), meaning its probability estimates are less reliable than the other models.
KNN Respectable results (90.77 % accuracy, AUC 0.9506), but it lags behind Logistic Regression and SVM. Train accuracy was 93.45 %, so there is a small but meaningful generalisation gap. KNN must store the entire training set and re-computes distances at prediction time, making it slower in production.
Naïve Bayes Lowest accuracy (83.28 %) and MCC (0.6946), but the highest recall (0.9587), meaning it catches nearly every spam email. The trade-off is low precision (0.7146): many legitimate emails are incorrectly flagged as spam. This is expected because the Gaussian NB independence assumption is violated — spam-related words are highly correlated with each other.
Support Vector Machine Almost as good as Logistic Regression (92.73 % accuracy, MCC 0.8471) and has the best precision (0.9277), so it makes the fewest false positives — important in a spam filter where wrongly blocking a legitimate email is costly.
Overall Winner Logistic Regression — best on accuracy, AUC, F1 and MCC with no overfitting. SVM is very close; the gap may be noise on this particular test split, making either a valid production choice.
